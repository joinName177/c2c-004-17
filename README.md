# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- **公制（厘米 / 千克）与英制（英寸 / 磅）一键切换**：输入、清单、图上尺寸、指标与打印统一采用所选单位
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存与打印清单

## 单位制策略

- 所有基础物理值始终以**厘米 / 千克**保存，装箱引擎与风险判定只读取这份基础值。
- 切换到英制只改变**展示文本**与**后续输入的解释方式**（英寸按 25.4 mm、磅按 453.59237 g 换算后写入 cm/kg），不会对已保存的值反复换算，也不会重新生成方案——装入数量与摆放坐标保持不变。
- 显示精度（cm 一位、in 两位、kg/lb 两位）仅用于四舍五入展示；“是否恰好超限”一律由未舍入的物理值决定。
- 表单采用“编辑草稿 → 提交 / 取消”模式：空值、无法解析或非正的数字不会写入；存在未确认输入时必须先提交或取消才能切换单位。
- 单位偏好随快照保存在本地；旧规划或缺失字段默认公制，多次切换并刷新后数量与位置不变。

## 分层架构

- `src/core`：领域模型、单位换算与输入解析、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

docker compose up --build
